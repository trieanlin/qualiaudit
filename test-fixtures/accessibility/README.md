# Accessibility stress fixtures

These CSV files contain fictional records created only for QualiAudit testing.
They intentionally include long identifiers, long rationales, mixed English
and Chinese text, and long source labels. They do not describe real
participants, interviews, institutions, or research findings.

Use `long-unicode-codebook.csv` and `long-unicode-excerpts.csv` together when
manually checking wrapping, reflow, queue and case layouts, and exported audit
records.
